# My YouTube uploader

A small tool I wrote for my own use. It runs on my own computer and uploads my own videos, with their titles, descriptions and thumbnails, to my own YouTube channels, after I have checked each batch. It is not offered to anyone else.

## Privacy policy

- This tool uses YouTube API Services. It asks Google for two permissions: to upload videos (youtube.upload) and to see my channel (youtube.readonly). It uses the second only to check which channel it is signed in to before each upload.
- The sign-in tokens stay in a private folder on my computer. The tool sends data only to YouTube. It collects, sells and shares nothing.
- Its use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
- Google's handling of the data is covered by the [Google Privacy Policy](https://policies.google.com/privacy).
- Access can be removed at any time at [myaccount.google.com/connections](https://myaccount.google.com/connections).

## Terms of service

For personal use only, provided as is, with no warranty. Everything it uploads must follow the [YouTube Terms of Service](https://www.youtube.com/t/terms).
